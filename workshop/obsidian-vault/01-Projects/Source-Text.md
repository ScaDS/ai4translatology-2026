Participants explore how machine translation can support their work. A
translation memory stores previously translated segments, while chat memory
keeps earlier messages available within a conversation. In the workshop,
participants use a terminology resource and examples from a corpus to prepare
a draft translation. A language model can suggest revisions, but a human
reviewer checks meaning, preferred wording and suitability for the audience
before release.
