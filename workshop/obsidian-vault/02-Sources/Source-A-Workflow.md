# Source-A-Workflow

Provenance: fictional workshop source, authored for this exercise; not an external publication.

## A1

A translation brief describes the intended audience, purpose, text type and constraints of a translation task.

## A2

Saving a brief and terminology decisions as project notes makes it easier to reuse and inspect them later. It does not ensure that a language model will follow every instruction.

## A3

A fixed translation-and-review pipeline follows predefined steps. A coordinating agent may choose which specialist tools to call in response to a request.
