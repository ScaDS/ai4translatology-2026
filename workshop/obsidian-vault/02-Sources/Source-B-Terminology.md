# Source-B-Terminology

Provenance: fictional workshop source, authored for this exercise; not an external publication.

## B1

A project wording table records preferred expressions and the context in which they apply. A preferred expression is not necessarily the best choice outside that context.

## B2

Corpus examples can help inspect usage in context. A small, selected set of teaching examples does not establish how frequent an expression is in a language or domain.

## B3

Providing a wording table as prompt context differs from enforcing terminology in a dedicated checking tool. The model may ignore a row or extend its scope incorrectly.
