# Source-C-Review

Provenance: fictional workshop source, authored for this exercise; not an external publication.

## C1

A review should compare the translation with the source and the brief, including meaning, omissions, terminology and register.

## C2

An LLM reviewer can miss errors and report problems that are not actually errors. A second LLM response is not a guarantee of translation quality.

## C3

Ask the reviewer to quote supporting passages, then verify those quotes and the reasoning yourself. A source reference alone does not prove that the source supports the claim.
