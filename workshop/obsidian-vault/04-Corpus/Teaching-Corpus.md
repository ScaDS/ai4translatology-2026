# Teaching-Corpus

A miniature English–German parallel corpus: six hand-written examples for
this workshop. All examples are fictional, not extracts from published texts.
This is a lookup exercise, not evidence of representative usage or frequency.
Segment C05 deliberately conflicts with the current [[Wording-Table]].

| Segment | English | German | Context |
| --- | --- | --- | --- |
| C01 | Machine translation provides a first draft. | Maschinelle Übersetzung liefert einen ersten Entwurf. | Introductory teaching text |
| C02 | A translation memory stores translated segments. | Ein Translation Memory speichert übersetzte Segmente. | CAT introduction |
| C03 | The corpus contains examples of academic language. | Das Korpus enthält Beispiele wissenschaftlicher Sprache. | Corpus introduction |
| C04 | Participants compare two draft translations. | Teilnehmende vergleichen zwei Übersetzungsentwürfe. | Workshop description |
| C05 | Check the translation memory before release. | Prüfen Sie das Übersetzungsgedächtnis vor der Freigabe. | Older wording; not preferred for the current webpage |
| C06 | Chat memory contains earlier messages. | Der Chatverlauf enthält frühere Nachrichten. | Chat interface explanation |

There is no current example here establishing the preferred translation of
"release" as "Veröffentlichung"; that choice comes from W08 and the brief.
