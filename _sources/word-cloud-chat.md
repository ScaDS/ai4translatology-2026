# Word clouds for Non-Programmers

In this exercise, we will create a word-cloud visualization of a speech given and published by Anthony Albanese MP, Prime Minister of Australia, under [CC-BY 4.0](https://pmtranscripts.pmc.gov.au/copyright) license. First, [download the speech text](Speech_Australian_PM.txt).

Log in to a AI-Chat-System of your choice, such as [julius.ai](https://julius.ai/), [ChatGPT](https://chatgpt.com/), [Claude](claude.ai), or [Gemini](https://gemini.google.com/app). Upload the speech text file and ask the AI system to draw a word cloud from it.

If you have basic coding skilly, create a new notebook in [Google Colab](https://colab.research.google.com/), generate code for drawing the word cloud.

## Discussion points

Discuss in the group advantages and disadvantages of the used approach.

* How were the wordclouds made?
* Is the code available that was used to process the data?
* If you wanted to perform the same analysis again, would the result look identical?
